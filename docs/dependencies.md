# Dependency register

Every dependency is listed here with what it does, the main alternative, and why it won.
**Adding, removing or swapping a dependency means updating this file in the same PR.** CI runs
`pnpm check:deps`, which fails if any `package.json` dependency is missing from this file or if
this file lists a package that is no longer installed. Bigger choices also get an
[ADR](adr/README.md).

Format: each package name appears once, in backticks, in the first column.

## Overrides (`pnpm-workspace.yaml`)

Forced versions of indirect dependencies, each a security fix the direct dependency hasn't shipped.
Remove an override as soon as its reason is gone. **None at the moment.**

History: `@esbuild-kit/core-utils>esbuild` (#30) forced esbuild past
[GHSA-67mh-4wv8-2f99](https://github.com/advisories/GHSA-67mh-4wv8-2f99) under drizzle-kit 0.31's
deprecated `@esbuild-kit` loader. It was removed when drizzle-kit moved to 1.0, which ships bundled
with no dependencies at all. (#30 said 1.0.0-rc.5 still used `@esbuild-kit`; that was a misread.)

## Agent tooling

Skills and plugins that shape how coding agents work on this repo. They're instructions, not
runtime code, but they change the output as much as a library would, so they're tracked here too.

| Tool                                                                                                           | Purpose                                                                                                                                                                                        | Alternative                                                                       | Why this one                                                                                                                                                                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| anti-slop skill (`dmmulroy/anti-slop`, `.claude/skills/install-anti-slop/`, pinned in `skills-lock.json`)      | Installs vendored Oxlint rules that reject patterns common in low-quality generated TypeScript (unchecked type assertions, `unknown` leaking through APIs, module mocking, quadratic reducers) | typescript-eslint's `strict-type-checked` preset alone, hand-written ESLint rules | The rules target the specific habits agents fall into, and they're copied into the repo, so we own and can change them.
