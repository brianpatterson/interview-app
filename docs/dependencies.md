# Dependency register

Every dependency is listed here with what it does, the main alternative, and why it won.
**Adding, removing or swapping a dependency means updating this file in the same PR.** CI runs
`pnpm check:deps`, which fails if any `package.json` dependency is missing from this file or if
this file lists a package that is no longer installed. Bigger choices also get an
[ADR](adr/README.md).

Format: each package name appears once, in backticks, in the first column.

## Runtime: API (`apps/api`)

| Package       | Purpose                                                                                                          | Alternative                                | Why this one                                                                                                                                                                                                                                                                                                                                                        |
| ------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fastify`     | HTTP server and routing                                                                                          | Express, Hono                              | Fast, first-class TypeScript, async error handling, `inject()` for testing without a port. Express is slower with weaker types; Hono's strengths (edge runtimes) aren't needed. [ADR-0007](adr/0007-separate-spa-and-rest-api.md)                                                                                                                                   |
| `drizzle-orm` | Type-safe queries                                                                                                | Prisma, Kysely                             | SQL-shaped TS API with no codegen and a thin runtime. Prisma hides SQL and is heavier; Kysely has no migration generation. [ADR-0004](adr/0004-drizzle-orm-and-migrations.md)                                                                                                                                                                                       |
| `pg`          | Postgres driver (node-postgres)                                                                                  | `postgres` (porsager)                      | The most widely used Node driver, supported by Drizzle and every hosting guide. `postgres` is faster but less common in docs and examples.                                                                                                                                                                                                                          |
| `zod`         | Runtime validation of requests                                                                                   | Valibot, TypeBox                           | Industry standard, and shared with the web app as the contract. Valibot is smaller (matters for browsers, less so here); TypeBox fits Fastify's JSON Schema validation but is less ergonomic. [ADR-0005](adr/0005-shared-zod-contract.md)                                                                                                                           |
| `better-auth` | Auth: sessions, email/password, OAuth, CSRF checks, rate limiting (also used by `apps/web` for its React client) | Clerk/WorkOS (managed), Lucia, hand-rolled | Self-hosted in our Postgres via the Drizzle adapter, open source and inspectable, with security-critical pieces (scrypt, PKCE, origin checks) implemented and tested upstream. Managed providers hide the mechanics and hold user data; Lucia is no longer maintained as a library; hand-rolling risks subtle security bugs. [ADR-0011](adr/0011-authentication.md) |

## Runtime: Web (`apps/web`)

| Package                 | Purpose                                   | Alternative                  | Why this one                                                                                                                                                                      |
| ----------------------- | ----------------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `react`                 | UI library                                | Vue, Svelte                  | The largest ecosystem and job market, which serves the learning goal. Svelte is lighter but less transferable.                                                                    |
| `react-dom`             | React's browser renderer                  | (none; it's part of React)   | Required to render React in the browser.                                                                                                                                          |
| `@tanstack/react-query` | Server-state cache, refetching, mutations | SWR, hand-rolled `useEffect` | Handles caching, invalidation after writes, and retries, with first-class mutations. SWR is lighter but weaker for mutations; hand-rolled fetching re-implements all of it badly. |

## Build and dev tooling

| Package                     | Purpose                                                    | Alternative                                                 | Why this one                                                                                                                                                                                                                                   |
| --------------------------- | ---------------------------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `typescript`                | Type checker                                               | TypeScript 7 (native Go port)                               | Pinned to `~6.0` because `typescript-eslint` doesn't support TS 7 yet. Move to 7 when it does (much faster type-checking).                                                                                                                     |
| `esbuild`                   | Bundles the API into one ESM file for the production image | `tsc` + copying `node_modules`, running `tsx` in production | One file and no `node_modules`, so the runtime image only needs Node. Also inlines the TypeScript-source workspace package. `tsc` would still need every runtime dependency installed in the image; `tsx` transpiles at startup in production. |
| `vite`                      | Dev server and bundler for the web app                     | webpack, Parcel                                             | Near-instant dev server, the default for new React apps, a simple config. webpack is slow and verbose.                                                                                                                                         |
| `@vitejs/plugin-react`      | React support (JSX, Fast Refresh) in Vite                  | `@vitejs/plugin-react-swc`                                  | The official default. The SWC variant is faster on big apps, which doesn't matter at this size.                                                                                                                                                |
| `tsx`                       | Runs the API's TS directly in dev, with watch mode         | `ts-node`, Node's built-in type stripping                   | Fast (esbuild), zero config, handles path and ESM quirks. Node's native stripping doesn't support some TS syntax; ts-node is slower and fussier with ESM.                                                                                      |
| `drizzle-kit`               | Generates SQL migrations from the schema                   | Hand-written SQL migrations                                 | Diffs `schema.ts` against migration history, so humans review generated SQL instead of writing it.                                                                                                                                             |
| `vitest`                    | Test runner                                                | Jest, `node:test`                                           | Native ESM and TS, Jest-compatible API, fast. Jest needs transform config for ESM and TS; `node:test` lacks a mature ecosystem.                                                                                                                |
| `eslint`                    | Linter                                                     | Biome, oxlint                                               | The broadest rule ecosystem (React hooks, typescript-eslint). Biome is faster and also formats, but has fewer rules. Revisit if linting gets slow.                                                                                             |
| `@eslint/js`                | ESLint's recommended JS rules                              | (none; part of ESLint)                                      | The base rule set for flat config.                                                                                                                                                                                                             |
| `typescript-eslint`         | TS parser and rules for ESLint                             | (none; the standard)                                        | The only maintained way to lint TS with ESLint.                                                                                                                                                                                                |
| `eslint-plugin-react-hooks` | Enforces the Rules of Hooks                                | (none; the standard)                                        | Catches hook-ordering and dependency bugs that types can't.                                                                                                                                                                                    |
| `globals`                   | Browser and Node global definitions for ESLint             | Declaring globals by hand                                   | The standard companion to ESLint flat config.                                                                                                                                                                                                  |
| `prettier`                  | Code formatter                                             | Biome, dprint                                               | Universal editor support and the de facto standard. Biome formats faster but is a second tool to learn alongside ESLint.                                                                                                                       |

## Tools and infrastructure (outside package.json)

These aren't checked by CI. Keep them current by hand.

| Tool                        | Purpose                                                                                                | Alternative                                 | Why this one                                                                                                                                                                                                                                                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Node.js 26 (LTS)            | JavaScript runtime                                                                                     | Bun, Deno                                   | The most compatible runtime everywhere you deploy. Bun is faster but has occasional compatibility gaps.                                                                                                                                                                                                                                      |
| pnpm                        | Package manager and workspaces                                                                         | npm, Bun, Yarn                              | Strict `node_modules` (no phantom dependencies), fast, excellent workspace support.                                                                                                                                                                                                                                                          |
| fnm                         | Node version manager                                                                                   | nvm, Volta, mise                            | Fast (Rust), reads `.node-version`, switches automatically on `cd`. nvm is slow to start the shell. mise manages many languages, which isn't needed yet.                                                                                                                                                                                     |
| OrbStack                    | Docker on macOS                                                                                        | Docker Desktop, Colima                      | Lighter and faster on Apple Silicon. Docker Desktop is heavier and needs a paid license for larger companies.                                                                                                                                                                                                                                |
| PostgreSQL 17 image         | Database                                                                                               | see [ADR-0003](adr/0003-postgresql.md)      |                                                                                                                                                                                                                                                                                                                                              |
| GitHub Actions              | CI                                                                                                     | CircleCI, GitLab CI                         | Built into GitHub, free for this use, no extra account.                                                                                                                                                                                                                                                                                      |
| Dependabot                  | Automated dependency and security update PRs                                                           | Renovate                                    | Built into GitHub with zero setup, and handles security advisories natively. Renovate is more configurable (better monorepo grouping, auto-merge rules) and worth a look if Dependabot gets noisy. [ADR-0010](adr/0010-public-repo-and-supply-chain-scanning.md)                                                                             |
| Dependency review action    | Blocks PRs that add vulnerable or GPL-licensed packages                                                | Socket, Snyk                                | Free on public repos and uses GitHub's advisory database. Socket also catches malicious packages (typosquats, install-script malware) but is another account to manage.                                                                                                                                                                      |
| CodeQL                      | Static security analysis of our code and workflows                                                     | Semgrep                                     | Free on public repos, deep data-flow analysis for JS/TS, and results in the Security tab. Semgrep is faster with easier custom rules, but its best rules need a paid account.                                                                                                                                                                |
| DigitalOcean                | Production droplet, volume, reserved IP, firewall, monitoring                                          | Hetzner, Vultr, Linode, OVHcloud            | $6/month in New York with an excellent OpenTofu provider and docs. Hetzner US came to 20.49/month for this account; Vultr and Linode are $1 cheaper with slightly weaker tooling; OVHcloud gives more RAM but clunky IaC. [ADR-0013](adr/0013-digitalocean-instead-of-hetzner.md)                                                            |
| OpenTofu                    | Infrastructure as code (`infra/`)                                                                      | Terraform, Pulumi, Ansible                  | Open-source (MPL) fork of Terraform with the same language and providers, so the skills transfer directly. Pulumi uses TypeScript but has more magic; Ansible configures servers but doesn't create them. Its built-in state encryption, which Terraform lacks, protects the keys in state ([ADR-0016](adr/0016-remote-encrypted-state.md)). |
| OpenTofu `tls` provider     | Generates the server's SSH host key and the deploy key                                                 | `ssh-keygen` by hand                        | Keys are reproducible from state, the host key survives droplet replacement, and CI gets a pinned `known_hosts` line, so nobody copies keys around by hand. The private keys live in state, which is already secret.                                                                                                                         |
| GitHub Container Registry   | Stores the production images, tagged by git SHA                                                        | Docker Hub, DigitalOcean Container Registry | Free for public repos, and the workflow authenticates with its own short-lived token, so there are no extra credentials. Docker Hub rate-limits pulls; DigitalOcean's registry costs money above the starter tier. [ADR-0014](adr/0014-push-based-deploys.md)                                                                                |
| ShellCheck                  | Lints the deploy and infra shell scripts in CI                                                         | Rewriting them in Node/TS                   | Catches quoting and error-handling bugs in the scripts that touch production. The scripts are small enough that a rewrite isn't worth it.                                                                                                                                                                                                    |
| cloud-init                  | First-boot server setup and hardening                                                                  | Ansible, a custom image (Packer)            | Built into Ubuntu and Hetzner, declarative, no extra tooling. Ansible is better for ongoing configuration drift, which a disposable server avoids.                                                                                                                                                                                           |
| Cloudflare DNS              | DNS for the domain, managed by OpenTofu                                                                | Registrar DNS (Wix), DigitalOcean DNS       | Free, fast, a first-class OpenTofu provider, and a CDN/WAF available later with one flag. Wix DNS has no API.                                                                                                                                                                                                                                |
| Cloudflare R2               | Off-site storage for backups (`<domain>-backups`) and encrypted OpenTofu state (`<domain>-tofu-state`) | DigitalOcean Spaces, Backblaze B2           | Free up to 10 GB with no download fees, S3-compatible, lifecycle rules and bucket locks, and run by a different company than the server (off-site). Spaces is $5/month flat. [ADR-0013](adr/0013-digitalocean-instead-of-hetzner.md), [ADR-0015](adr/0015-backups.md), [ADR-0016](adr/0016-remote-encrypted-state.md)                        |
| Caddy (`caddy:2.11-alpine`) | TLS, static SPA, `/api` reverse proxy, security headers                                                | nginx + certbot, Traefik                    | Automatic HTTPS with near-zero config. nginx needs certbot and renewal cron jobs; Traefik shines with dynamic container discovery we don't need.                                                                                                                                                                                             |
| node:26-slim image          | API runtime base image                                                                                 | `node:26-alpine`, distroless                | Debian/glibc avoids musl surprises with native modules. | AWS CLI (on GitHub runners) | Uploads and downloads backups through R2's S3 API                                                      | rclone, `wrangler r2`                       | Preinstalled on GitHub's runners, so there's nothing to install or pin. rclone is better for syncing many files; wrangler needs a Cloudflare API token instead of a bucket-scoped S3 key.                                                                                                                                                    |
| Resend                      | Sends password reset and sign-up confirmation emails (HTTP API, called with `fetch`, no SDK)           | Postmark, Amazon SES, `resend` npm SDK      | Free up to 3,000 emails a month, simple domain setup, and a dashboard of every email. Postmark has no free plan; SES starts in a sandbox and needs an AWS account. The SDK would be a dependency for one POST request. [ADR-0017](adr/0017-email-resend.md)                                                                                  |
| pg_dump / pg_restore        | Logical backups and restores                                                                           | pgBackRest, WAL-G, volume snapshots         | Consistent snapshots of a live database, portable and tiny at this size, run from the same `postgres:17` image. WAL archiving gives point-in-time recovery but isn't worth its complexity yet. [ADR-0015](adr/0015-backups.md)                                                                                                               |
